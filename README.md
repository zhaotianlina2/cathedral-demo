# 罗马大教堂：交互式 3D 场景

一个可在浏览器中探索的 Three.js 罗马大教堂场景：通过旋转、缩放、平移与预设视角，从不同角度查看建筑及周边广场。

## 功能与交互

- 展示以罗马大教堂为主题的 3D 场景。
- 使用鼠标左键拖动旋转视角、滚轮缩放、右键拖动平移。
- 提供「正面」「广场」「鸟瞰」三个视角预设。
- 可切换「环绕」和「夜景」模式。

## 技术与文件

- Three.js / WebGL：渲染浏览器中的 3D 场景。
- `cathedral_standalone.html`：独立页面，包含场景及界面代码。
- `three.module.min.js`：仓库内的 Three.js 模块文件。
- 仓库未包含常见包管理器清单或构建配置；GitHub Actions 工作流提供手动触发的 GitHub Pages 发布流程。

## 本地查看

无需安装构建依赖。直接在现代浏览器中打开 `cathedral_standalone.html` 即可尝试。页面使用 WebGL；实际效果取决于浏览器和设备支持。

## 发布

仓库中的 `.github/workflows/deploy-pages.yml` 定义了手动触发的 GitHub Pages 部署工作流。是否已部署及公开访问地址，需以仓库当前 Pages 设置和部署结果为准。

## 操作提示

在场景中拖动或滚动调整观察角度与距离；也可用页面上的视角和模式按钮快速切换。
